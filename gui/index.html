The usual flow

  1. Get Amazon orders (Amazon sync). Refreshes the local copy of your order history. Nothing in YNAB changes.
  2. Build the analysis (Analyze – Amazon only). Pulls your unapproved Amazon transactions from YNAB, matches them to orders, and saves the result to a local file. Nothing in YNAB changes.
  3. Look it over on the Transactions tab. You can pick categories right in the table.
  4. Memos only (Memo apply). Preview, then write memos for the confident matches. Categories and approval stay untouched.
  5. When you're ready: choose categories or splits on the Transactions tab, then send them with Apply categories (preview first, with "Only the ones I chose" on).

The analysis file is a snapshot. When new charges show up in YNAB, run Analyze again before Memo apply.

What each badge means

Read-only Only reads from YNAB or Amazon. Safe to run any time.

Local files Saves files in this folder's data folder. Doesn't touch YNAB.

Memo write Preview by default. The red button changes memos in YNAB only.

Category write Preview by default. The red button sets categories and approval in YNAB.
